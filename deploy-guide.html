1

Open Google Apps Script

Click the button below to open Google Apps Script:

Open Google Apps Script
2

Create New Project

  • Click "New Project" button
  • You'll see a code editor with default code
  • Delete ALL the existing code
3

Paste This Code

Copy the code below and paste it into the editor:

const SHEET_ID = '1nrMBnmgdjtefTNzW0ZBzeOp_mvBHBdSLeFHW_qPfLeo'; function doGet(e) { try { const spreadsheet = SpreadsheetApp.openById(SHEET_ID); const sheets = spreadsheet.getSheets(); let allData = []; sheets.forEach(sheet => { const sheetName = sheet.getName(); const data = sheet.getDataRange().getValues(); if (data.length <= 1) return; const headers = data[0]; const rows = data.slice(1); rows.forEach(row => { const obj = {}; headers.forEach((header, index) => { const key = header.toString() .toLowerCase() .replace(/[^a-z0-9]+/g, '_') .replace(/^_|_$/g, ''); obj[key] = row[index]; }); obj['_sheet_name'] = sheetName; if (obj['name'] || obj['name_mm'] || obj['short_name']) { allData.push(obj); } }); }); return ContentService .createTextOutput(JSON.stringify(allData)) .setMimeType(ContentService.MimeType.JSON); } catch (error) { return ContentService .createTextOutput(JSON.stringify({ error: error.message })) .setMimeType(ContentService.MimeType.JSON); } }
4

Deploy as Web App

  • Click "Deploy" button (top right)
  • Select "New deployment"
  • Click the gear icon ⚙️
  • Select "Web app"
  • Fill in:
    • Description: "Myanmar NRC Search API"
    • Who has access: "Anyone" (IMPORTANT!)
  • Click "Deploy"
  • Click "Copy" to copy the URL
5

Update app.js

Open app.js and find this section:

sheet1: { url: '', // ← Paste your URL here searchColumn: 'Name', nameKey: 'name', detailKey: 'details' },

Replace the empty url: '' with the URL you copied.

6

Test the App

  • Open index.html in your browser
  • Type "Taungdwingyi" in the search box
  • Click "Search"
  • You should see results with Name, Name MM, Short Name MM, Short Name, and Region!
