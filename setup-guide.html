MM Data Search - Setup Guide

1

Deploy Google Apps Script for Sheet 1

  • Go to https://script.google.com/
  • Click "New Project"
  • Delete all existing code
  • Copy and paste the code from google-apps-script.gs
  • Update the SHEET_ID with your Sheet 1 ID:
const SHEET_ID = '1nrMBnmgdjtefTNzW0ZBzeOp_mvBHBdSLeFHW_qPfLeo';
  • Click "Deploy" > "New deployment"
  • Click the gear icon > select "Web app"
  • Set "Who has access" to "Anyone"
  • Click "Deploy" and copy the URL
2

Deploy Google Apps Script for Sheet 2

  • Go back to https://script.google.com/
  • Click "New Project" again
  • Delete all existing code
  • Copy and paste the code from google-apps-script.gs
  • Update the SHEET_ID with your Sheet 2 ID:
const SHEET_ID = '1VcB_oia94R7dqRTl7U7fhxQznCwgnxDlHNCDN8ygagM';
  • Click "Deploy" > "New deployment"
  • Click the gear icon > select "Web app"
  • Set "Who has access" to "Anyone"
  • Click "Deploy" and copy the URL
3

Update app.js Configuration

Open app.js and find the CONFIG section. Replace the empty URLs:

const CONFIG = { sheet1: { url: 'PASTE_YOUR_SHEET1_URL_HERE', // ... }, sheet2: { url: 'PASTE_YOUR_SHEET2_URL_HERE', // ... } };
4

Test the App

  • Open index.html in your browser
  • Type "Yesagyo" in the search box
  • Click "Search"
  • You should see results from your Google Sheet!
Note: The app automatically converts your Google Sheet headers to lowercase with underscores. For example:
  • "Name" becomes "name"
  • "Town_Township" stays as "town_township"
  • "Phone Number" becomes "phone_number"
Important: Make sure you set "Who has access" to "Anyone" when deploying the Apps Script, otherwise the web app won't be able to access your data.
